# 🎵 Music Player

A simple yet stylish **Music Player** built with **HTML, CSS, and JavaScript**.  
This project provides essential music player functionality with a clean UI and smooth user experience.

## ✨ Features

- ▶️ Play / ⏸ Pause music
- ⏭ Next / ⏮ Previous track navigation
- 📊 Interactive progress bar with draggable seek
- ⏱ Real-time current time & total duration display
- 🎶 Dynamic track info (title, artist, album cover)
- 📱 Fully responsive modern UI

## 🛠 Tech Stack

- **HTML5** – Semantic structure  
- **CSS3** – Responsive design & animations  
- **JavaScript (ES6)** – Audio logic & DOM manipulation
